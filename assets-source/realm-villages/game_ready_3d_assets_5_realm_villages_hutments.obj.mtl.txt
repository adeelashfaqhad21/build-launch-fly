# Game-Ready 3D Asset Library: 5 Realm Villages & Hutments (.OBJ & .MTL)
### Low-to-Mid Poly Mobile Assets (1 Unit = 1 Meter | Forward = +Z | Up = +Y | Ground Pivot = (0, 0, 0))

This production package provides the geometric Wavefront OBJ (`.obj`) meshes and Material Template Library (`.mtl`) definitions for all 5 distinct realm settlements. Each building is optimized for mobile performance (500–2500 triangles per asset), featuring clean quad/tri topology, ground contact pivots `(0, 0, 0)`, and distinct architectural vocabularies.
