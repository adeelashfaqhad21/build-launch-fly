# Realm village asset integration

Runtime composite meshes in `app/src/main/assets/villages/` are assembled from the supplied OBJ house/support components and the shared `realms_architecture.mtl`.

## Realm mapping
- Greenwood Forest: four log/timber huts and a stone/timber well.
- Highland Valley: rural cottage, L-shaped farmhouse, barn, granary and windmill (source pack's Plains realm).
- Amber Dunes: adobe homes, stepped terrace house, domed shrine, courtyard compound and watchtower.
- Glacier Reach: winter longhouse, alpine A-frame, snow mound hut, insulated cabin and signal beacon.
- Sapphire Coast: stilt cottage, maritime townhouse, boat-keel dwelling, harbor shed and lighthouse.

The five source `*_Village_Cluster.obj` blocks are comments-only layout notes, not meshes. The runtime composites are therefore assembled from the individual house/support OBJ geometry. The original uploaded source document is preserved unchanged alongside this README.
