Build • Launch • Fly — Poly Haven terrain runtime texture package

This package contains only the five 1K base-colour (diffuse/albedo) maps needed by the current Android renderer's single-albedo terrain shader.

Files:
- terrain/grass_ground_1k.jpg       -> grass/meadow surface
- terrain/dense_sand_1k.jpg         -> desert and sandy coastal surface
- terrain/rocky_terrain_02_1k.jpg   -> exposed rock surface
- terrain/snow_02_1k.jpg            -> snow and ice/snowfield surface (until a distinct ice material is selected)
- terrain/forest_ground_06_1k.jpg   -> forest-floor/bare-soil patches

Not included intentionally:
- .blend files: the game uses a custom OpenGL ES renderer and cannot load Blender project files.
- displacement maps: current terrain geometry is generated by the game's heightfield and the terrain shader has no displacement sampling.
- EXR normal/roughness maps: the current terrain shader does not sample tangent-space normal or per-pixel roughness maps; Android BitmapFactory does not decode EXR.
- specular/translucency maps: not consumed by the current terrain material.

The included JPGs are already 1K and directly decodable by Android BitmapFactory. This is a source handoff package; the game code still needs to be wired to load these files before they affect rendering.
