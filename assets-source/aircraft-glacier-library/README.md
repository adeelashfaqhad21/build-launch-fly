# Aircraft and Glacier Asset Library

Original supplied OBJ/MTL specification is preserved in this directory.

World mapping: Greenwood Forest—Skyhopper; Amber Dunes—VintageBiplane; Glacier Reach—FrostFreighter; Sapphire Coast—AuroraScout; Highland Valley—ViperStrike.

Runtime aircraft meshes are under `app/src/main/assets/aircraft/worlds/`. Glacier flora OBJ/MTL files are under `app/src/main/assets/glacier/`.
