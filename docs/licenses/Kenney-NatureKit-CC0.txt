Pack contents (330 files): low-poly trees, palms, rocks, stones, bushes, flowers, grass,
mushroom and plant models, in GLTF / FBX / OBJ plus a single shared palette texture
(Textures/colormap.png). The OBJ models are the ones the game loads.

Shipped as: app/src/main/assets/kits/kenney_nature.zip
The archive is read in memory at load time (gfx/ZipKit), so no build-time unpack step is
needed, and the game only pays texture memory for the models it actually places.
