Pack contents (75 files, version 2.0): a modular low-poly medieval set — wall sections,
towers, gates, stairs, roofs, doors, windows, banners and flags — in GLTF / FBX / OBJ with a
single shared palette texture. The OBJ models are the ones the game loads.

Intended use in this project: a ruin on every realm's skyline — a three-piece tower
(tower-square-base, tower-square-mid, tower-square-roof) with a wall run beside it
(wall, wall-doorway) — dressed with the kit's own colormap.png atlas.

Shipped as: the pieces actually placed are copied into app/src/main/assets/models/castle/
with the shared colormap.png; the model .obj files are read at load time by
gfx/PropLoader.loadScaled, which applies one shared scale to the whole modular set so the
stacked tower lines up. The 2 MB source archive is kept out of the APK; the open-source kit
stays in assets-source/.
