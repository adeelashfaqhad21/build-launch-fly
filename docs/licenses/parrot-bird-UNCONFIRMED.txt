parrot-light.glb — bird model for the flock

Supplied by the project owner and dropped into assets-source/ on request; the file was copied
into app/src/main/assets/birds/parrot.glb and is loaded by gfx/GlbLoader.

Provenance and licence are NOT stated by the file itself and were not given with it. Before
this ships publicly the source needs to be recorded here — the file looks like a stock glTF
sample rather than an original model. Treat it as unconfirmed until then.

Format: glTF 2.0 binary (.glb), JSON + BIN chunks, one or more static primitives. The
renderer only reads POSITION, NORMAL, TEXCOORD_0 and indices; no skinning or animation.
