ambientCG publishes every asset under CC0: no attribution is required, and commercial use
is allowed. Attribution is given here and in the README as a courtesy.

Assets included in this build (2048² JPG colour maps, under app/src/main/assets/terrain/):

  rubber.jpg  <- "Rubber 004"        https://ambientcg.com/a/Rubber004
  hazard.jpg  <- "Painted Metal 016" https://ambientcg.com/a/PaintedMetal016

Only the base-colour (albedo) map of each set ships: the shader samples one map per
surface today, so the normal, roughness, ambient-occlusion and displacement maps were left
out. The original 1K archives (Rubber004_1K-JPG.zip, Sign004_1K-JPG.zip) stay in the
git-ignored assets-source/ambientcg/ and are not part of the APK.

Each map is downscaled on load (max 512 px) and uploaded mip-mapped.

Where the game uses them:

  rubber.jpg -> the spinning propeller's motion-blur disc (AircraftMesh.propellerBlurMaterial)
                and the bird material (WorldScene.birdMaterial)
  hazard.jpg -> the slingshot's warning-striped elastic band (SlingshotMesh.bandMaterial)

Both are read through gfx/TextureFactory, which falls back to the generated map if the file
is missing, so a renamed asset can never break a world.
